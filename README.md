# Breathe v15 — Independent Audio Layers and Binaural Controls

Upload the contents of this folder to the root of your GitHub Pages repository, replacing the previous app files.

## Audio architecture
- `breathe_bowls_v3.wav`: continuous singing-bowl layer (the version approved as good enough for now).
- `breathe_water.wav`: separate subtle water ambience layer.
- Binaural tones are generated by the browser Web Audio API, with independently adjustable base carrier, binaural difference, variation range, variation speed, and level.
- Optional phase-change chimes remain independent from the continuous soundscape.

Default binaural settings: 180 Hz base carrier, 4 Hz difference, ±20 Hz variation, 60-second main movement, 8% level.

## iPad/PWA notes
Audio playback must be initiated by a user gesture (Preview or Begin). Use stereo headphones for the intended binaural effect. Browser/PWA audio may pause when iPadOS backgrounds the app. Settings and exercises remain in local browser storage.

The bowl and water WAVs are separate layers recreated for this project; they are not mathematically isolated stems from the reference mix.

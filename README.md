# Breathe v8 — Balanced Abstract

This is the first v8 redesign pass, built on the existing working exercise engine.

## Included
- New Balanced Abstract visual styling: warm cream, sage, ochre, terracotta, indigo and pale blue.
- New home screen with Calm, Energize, Sleep and Awaken mood choices.
- Time-of-day and weekday-based suggestion copy.
- Existing custom exercises, progressive exhale-hold template, voice selection/speed, sound toggles, import/export and settings retained.
- Service worker cache bumped to v8.

## Update on iPad
1. Download and extract the ZIP in Files.
2. In your existing GitHub Pages repository, replace `index.html`, `sw.js`, `manifest.json` and `icon.svg` with these files.
3. Commit to the same branch and folder that GitHub Pages publishes.
4. Open the published site in Safari and refresh. Reopen the Home Screen app after the website has refreshed.

Keep a backup of your current repository files before replacing them.
